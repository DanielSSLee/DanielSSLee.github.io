📁Projects — C:\DanielOS\Projects\Zoho Data Automation

Zoho Data Automation Tool

Python, pandas, openpyxl, pywin32, requests, numpy, schedule, Power BI, Zoho Desk & FSM REST APIs

KW Internationals (May 2025 – July 2025)

Pipeline Architecture & Code Breakdown

1. Concurrent API Harvester (zohofsmExport.py & zohodeskExport.py):
- Multi-threaded pagination using ThreadPoolExecutor(max_workers=10) to pull OAuth2 tickets, requests, and work orders.
- Flattens complex JSON structures recursively (flatten_json()) and maps fields dynamically via custom text mapping files.
- Computes SLA Turnaround Times (TAT) using numpy.busday_offset and custom holiday arrays.
2. Template Injector & Formula Engine (insert_to_ticket.py & tickets_to_tickets.py):
- Uses openpyxl to clear old data and inject clean Request & Work Order records into Ticket_Template.xlsx.
- Formats closed timestamps with pandas.to_datetime() and populates dynamic Excel formulas (WORKDAY, NETWORKDAYS, VLOOKUP, IFERROR).
3. Win32 COM & Table Resizer (pywin32 / win32com.client):
- Interacts directly with Windows Excel COM interface (win32com.client.Dispatch("Excel.Application")).
- Dynamically calculates the new data range and resizes ListObject("Table1") automatically, prompting a native Windows message box via ctypes.windll.user32.MessageBoxW.
4. Pipeline Orchestration & Power BI Auto-Launch (run_pipeline.py):
- Multi-process execution using Python threading.Thread and subprocess.Popen.
- Automatically cleans COM cache (Del_Cache.py) and launches Power BI Desktop (CUCHEN Draft.v2.pbix) upon completion!
Python 3 ThreadPoolExecutor pandas openpyxl pywin32 (Win32 COM) numpy busday Power BI (.pbix)
